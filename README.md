# ai-portfolio

AI 应用开发作品集。四个项目，各自独立可运行，均为本人在 AI 应用方向的实际工程实践。

## 项目

| 目录 | 项目 | 技术栈 | 说明 |
|---|---|---|---|
| [corporate-travel-assistant](./corporate-travel-assistant) | 企业级差旅助手 | LangGraph + FastAPI + React | 多智能体行程规划 / 预订 / 实时监控，无 Key 自动降级 Demo 模式 |
| [enterprise-knowledge-assistant](./enterprise-knowledge-assistant) | 企业知识库问答 | RAG + 向量检索 + 重排序 | DOCX/PDF 批量入库、多轮对话记忆、JWT 权限、Docker 一键部署 |
| [cross-border-ecommerce-ai](./cross-border-ecommerce-ai) | 跨境电商智能平台 | FastAPI + Vue 3 + RAG | 智能客服 / 营销文案 / 实时翻译 |
| [personal-homepage](./personal-homepage) | 个人主页 | 单文件 HTML | 主页 / 术语小词典 / 技术详解 |

## 结构说明

- 每个子目录是一个独立项目，提交历史完整保留，可单独检出或分离成独立仓库。
- 各项目的启动方式、环境变量与依赖，见其目录内的 README。
