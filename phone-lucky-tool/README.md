# 手机截图手机号识别 & 吉凶查询

纯前端单文件工具：批量识别手机截图里的 11 位手机号，按正规号段校验并标注运营商，再勾选多个吉凶查询网站一键打开/生成查询链接。

## 功能

- **批量截图识别**：支持拖拽、多选上传，以及 `Ctrl/⌘+V` 直接粘贴截图（手机经微信输入法同步到电脑剪贴板后，点一下页面再粘贴即可），可连续粘贴多张。
- **浏览器本地 OCR**：基于 [Tesseract.js](https://github.com/naptha/tesseract.js) 在浏览器内识别，截图**不会上传**到任何服务器。
- **正规号段校验**：内嵌中国移动/联通/电信/广电/虚拟运营商号段白名单，仅保留前 3 位命中的候选号码，过滤 OCR 误拼出的非标准号段。
- **运营商识别**：每个号码自动标注「移动 / 联通 / 电信 / 广电 / 虚商」。
- **OCR 纠错**：自动去除空格，并将 `O→0`、`l/I→1`、`Z→2`、`S→5`、`B→8`、`g→9` 等常见误识替换后再匹配。
- **多网站吉凶查询**：内置百度/搜狗/必应聚合查询（一定能打开且会列出多个吉凶网站结果），支持自定义网站（URL 中用 `{PHONE}` 占位），可生成每个「号码 × 网站」的查询链接并一键打开/复制全部链接。

## 本地运行

OCR worker 在 `file://` 下会被浏览器跨域限制，须用 http 方式打开：

```bash
# 在项目目录下启动静态服务器（Python 自带）
python -m http.server 8765

# 浏览器访问
http://localhost:8765/index.html
```

## 使用步骤

1. 上传 / 粘贴多张手机截图
2. 点「开始识别」（默认英文/数字模式更快；截图含中文干扰时可切「中文+数字」）
3. 识别结果区查看去重后的手机号与运营商；可复制全部 / 导出 `.txt` / 查看原始 OCR 文本
4. 在「选择吉凶查询网站」区勾选网站，或添加自定义网站（URL 用 `{PHONE}` 代替号码）
5. 点「生成查询链接」，再「复制全部链接」粘到微信发手机打开，或「全部打开」在新标签查看吉凶结果

## 技术说明

- 单文件 `index.html`，零构建、零依赖安装（Tesseract.js 由 CDN 加载）。
- 手机号正则：`/1[3-9]\d{9}/g`，叠加号段白名单校验。
- 自定义吉凶网站配置保存在浏览器 `localStorage`，下次自动加载。

## 注意事项

- 浏览器可能拦截大量弹窗，「全部打开」若被拦，请在地址栏允许弹窗，或直接点生成的链接逐个打开。
- 真实吉凶网站多为表单提交、URL 参数格式不稳定，故默认采用搜索引擎聚合；如需固定某站，请按说明添加其查询 URL 模板。
- 吉凶测算结果仅作趣味参考，无科学依据。
