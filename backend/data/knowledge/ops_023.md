# FBA 库存绩效指标 IPI

## 1. IPI 的定义与重要性
IPI（Inventory Performance Index）是亚马逊衡量卖家库存管理能力的核心指标，满分为1000分。根据《亚马逊FBA政策》第4.5条，IPI低于450分将影响卖家的销售权限。

- IPI越高，表示库存管理越高效
- IPI低于450分，可能被限制上架新商品

## 2. IPI 的计算公式
IPI由三个关键指标组成：库存周转率、库存可售率和库存保留率。

| 指标 | 权重 | 计算方式 |
|------|------|-----------|
| 库存周转率 | 40% | 销售额 / 平均库存价值 |
| 库存可售率 | 30% | 可售库存 / 总库存 |
| 库存保留率 | 30% | 保留库存 / 总库存 |

## 3. 提升 IPI 的方法
提高IPI需要优化库存结构和销售策略。

- 定期清理滞销品
- 优化库存布局，提升可售率
- 加强促销活动，提高库存周转率
