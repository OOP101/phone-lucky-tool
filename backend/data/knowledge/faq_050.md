# 补发、补货与折扣补偿的适用场景

## 一、补发与补货的区别
- **补发**：指因缺货或发货错误导致的重新发货，通常由卖家承担运费。
- **补货**：指因库存不足导致的再次进货，由卖家负责采购与发货。

## 二、适用场景与操作流程
| 场景 | 操作方式 | 适用情况 |
|------|-----------|----------|
| 缺货 | 补发 | 买家下单后发现缺货 |
| 发货错误 | 补发 | 买家收到错误商品 |
| 库存不足 | 补货 | 产品热销导致库存不足 |
| 促销活动 | 折扣补偿 | 买家投诉或不满 |

## 三、补发与补货流程
1. **确认需求**：核实买家需求，确定是补发还是补货。
2. **安排发货**：补发商品需尽快发出，补货需重新采购并发货。
3. **通知买家**：及时告知买家发货进度与预计到达时间。
4. **处理售后**：若因补发导致延误，可适当补偿。

## 四、折扣补偿策略
- **适用情况**：买家投诉、延迟发货、商品瑕疵等。
- **补偿方式**：提供折扣券、满减优惠或赠品。
- **建议比例**：通常为订单金额的 10%-20%。

## 五、注意事项
- 补发与补货需在 24 小时内响应，避免客户流失。
- 折扣补偿需与平台政策一致，避免违规。
- 建议制定统一的售后处理流程，提升客户满意度。
