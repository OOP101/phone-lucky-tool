# 纯电池与移动电源出货要求

## 一、纯电池与移动电源定义

- **纯电池**：不含任何电子设备的独立电池单元，如锂电池。
- **移动电源**：内置电池的便携式充电设备，如充电宝。

## 二、运输限制与法规要求

| 项目       | 要求说明                                 |
|------------|------------------------------------------|
| 运输方式   | 仅限空运或专线物流，海运需特殊审批       |
| 包装要求   | 需防短路、防压，每件不超过200Wh          |
| 数量限制   | 单个包裹不得超过2个，总容量不超过100Wh  |
| 文件要求   | 需提供UN38.3测试报告、MSDS等             |

## 三、操作流程

1. 选择符合要求的物流渠道，如空运或专线物流。
2. 准备UN38.3测试报告、MSDS文件等材料。
3. 包装时确保电池固定，防止碰撞。
4. 向物流商提交申请，并确认运输方案。

## 四、注意事项

- 移动电源需额外提供产品说明书及安全认证。
- 避免将电池与金属物品混装，防止短路。
- 部分国家对电池运输有额外限制，如欧盟《REACH法规》第15条。
