# 欧盟 GDPR 通用数据保护条例

## GDPR 合规基本要求

GDPR（General Data Protection Regulation）是欧盟于2018年5月25日生效的数据保护法规，适用于所有处理欧盟公民个人数据的企业。

- **适用范围**：任何向欧盟用户提供服务或收集其数据的企业，无论企业所在地。
- **处罚金额**：最高可处全球年营业额4%或2000万欧元的罚款（以较高者为准）。
- **数据主体权利**：包括知情权、访问权、更正权、删除权、限制处理权、数据可携权和反对权。

## 数据处理合规步骤

1. **数据分类与评估**：识别并分类处理的数据类型，如姓名、地址、支付信息等。
2. **获得合法依据**：确保数据处理有明确的法律基础，如用户同意、合同履行或合法利益。
3. **数据最小化原则**：仅收集必要数据，避免过度采集。
4. **数据安全措施**：采用加密、访问控制、定期审计等手段保护数据安全。
5. **数据泄露通知**：在发生数据泄露时，需在72小时内向监管机构报告，并视情况通知用户。

## 合规工具与文档清单

| 工具/文档 | 说明 |
|----------|------|
| 数据处理协议 | 与第三方服务商签署，明确数据处理责任 |
| 隐私政策 | 明确告知用户数据使用方式 |
| 数据主体请求处理流程 | 建立响应机制，处理用户权利请求 |
| 数据安全评估报告 | 定期进行风险评估并记录 |
| 数据泄露应急预案 | 制定应对策略，确保快速响应 |

## 监管机构与联系方式

- **欧盟数据保护委员会（EDPB）**：[https://edpb.europa.eu](https://edpb.europa.eu)
- **各国数据保护局（DPA）**：如德国联邦数据保护局（BfD），法国国家信息与自由委员会（CNIL）等。

## GDPR 合规建议

- 定期培训员工，提高数据保护意识。
- 使用合规的第三方服务，如云存储、营销平台等。
- 在网站和应用中加入隐私弹窗，获取用户同意。
- 建立数据处理日志，便于审计与追踪。
