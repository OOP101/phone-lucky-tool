# 海运拼箱 LCL 的操作流程

## LCL 海运的基本概念

LCL（Less than Container Load）指多个货主的货物拼装在一个集装箱内运输，适用于中小批量发货。

## 操作流程

1. **订舱**：通过货代公司预订拼箱仓位；
2. **货物集港**：将货物送至指定港口的集货仓库；
3. **拼箱装柜**：货代将不同货主的货物拼装成一个集装箱；
4. **出运**：集装箱装船并启运；
5. **目的港清关与拆柜**：到达后进行清关并分拨货物。

## 计费方式

- **按体积计费**：每立方米约 100-200 元；
- **按重量计费**：每公斤约 10-20 元；
- **最低收费**：通常为 1000 元起。

## 适用场景

- **中小批量发货**：适合订单量较小的卖家；
- **成本敏感型**：相比整柜更具性价比；
- **多国发货**：可通过拼箱降低运输成本。

## 注意事项

- **货物分类**：需明确货物性质，避免混装；
- **清关文件**：需准备发票、装箱单、提单等；
- **运输时间**：通常为 20-40 天，视航线而定。

## 操作建议

1. 提前与货代沟通，确认拼箱计划；
2. 确保货物包装符合海运要求；
3. 选择可靠的货代公司，保障运输安全；
4. 定期跟进货物状态，及时处理问题。
