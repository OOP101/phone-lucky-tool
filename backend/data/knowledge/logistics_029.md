# 出口退运与返修货物流程

## 退运与返修定义
出口退运指因质量问题、客户取消等原因将货物退回原产地；返修货指客户寄回需要维修的货物。根据《中华人民共和国海关法》第40条，退运需重新申报。

## 退运流程
1. 客户提出退运请求，提供订单号与原因说明；
2. 与物流商协商退运方式（海运、空运）；
3. 准备退货申请文件（发票、合同、退运原因）；
4. 由物流商安排运输并提交海关申报。

## 返修流程
1. 客户寄回故障产品，注明“返修”字样；
2. 收货后进行检测，确定维修方案；
3. 维修完成后重新发货，附带维修证明；
4. 保留维修记录与客户沟通记录。

## 注意事项
- 退运需提前与物流商确认费用与时间；
- 返修货物需标注清晰，避免误操作；
- 保留所有相关文件，便于后续争议处理。

## 合规建议
- 遵守海关总署公告2020年第75号关于退运的规定；
- 与物流商签订明确的退运与返修协议。
