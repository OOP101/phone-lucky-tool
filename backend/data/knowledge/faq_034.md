# RoHS 2.0 有害物质限制要求

RoHS 2.0（指令 2011/65/EU）限制电子电气产品中六种有害物质的使用，适用于大多数电子产品。

## 一、限制物质

RoHS 2.0 规定的限制物质包括：

- 铅（Pb）
- 汞（Hg）
- 镉（Cd）
- 六价铬（CrVI）
- 多溴联苯（PBB）
- 多溴二苯醚（PBDE）

每种物质的限值如下：

| 物质 | 最大允许浓度 |
|------|----------------|
| Pb   | 0.1%           |
| Hg   | 0.1%           |
| Cd   | 0.01%          |
| CrVI | 0.1%           |
| PBB | 0.1%           |
| PBDE | 0.1%           |

## 二、适用范围

RoHS 2.0 适用于以下产品：

- 电动工具
- 家用电器
- IT 和通信设备
- 照明设备

## 三、合规要求

1. **材料检测**：对原材料进行有害物质检测。
2. **供应商管理**：要求供应商提供材料合格证明。
3. **产品标识**：在产品上标注 RoHS 合规信息。
4. **记录保存**：保留检测报告至少 10 年。

## 四、注意事项

- 未通过 RoHS 合规的产品无法进入欧盟市场。
- 建议采用替代材料以避免超标。
- 定期更新检测方法以适应法规变化。

| 产品类型 | 合规要求 | 检测频率 |
|----------|-----------|------------|
| 电子设备 | 材料检测 | 每年一次 |
| 电池 | 材料检测 | 每次采购 |
| 附件 | 材料检测 | 每季度一次 |
