# Coupon、Promotion 与 Deal 设置

## 一、Coupon 与 Promotion 区别

- **Coupon** 是针对特定产品的折扣券，用户需手动领取；
- **Promotion** 是平台统一促销活动，如“Prime Day”、“Lightning Deal”等；
- **Deal** 是限时折扣，通常由亚马逊审核后发布。

## 二、Coupon 设置流程

1. 登录卖家后台，进入「Coupons」页面；
2. 选择产品 ASIN，填写折扣金额与有效期；
3. 生成 Coupon Code 并分享给客户；
4. 亚马逊审核通过后生效。

## 三、Promotion 设置指南

- 选择促销类型（如 Buy One Get One Free、Free Shipping）；
- 设置促销时间（建议至少提前 3 天申请）；
- 上传促销图片（尺寸要求：1000×1000 像素）；
- 提交审核，等待通知。

## 四、Deal 设置要点

- 申请前需满足以下条件：
  - 产品评分 ≥ 4 星；
  - 有 50 条以上有效评论；
  - 无违规记录；
- 申请时需提供产品详情、价格截图及促销计划。

## 五、优惠组合建议

| 优惠类型 | 适用场景 | 建议搭配 |
|----------|----------|-----------|
| Coupon + Promotion | 提升转化 | 限时折扣+满减 |
| Deal + Coupon | 增加曝光 | 限时折扣+领券 |
| Promotion + Deal | 强化促销 | 买赠+限时 |

## 六、注意事项

- 所有促销活动需遵守亚马逊促销政策（条款号：Amazon Promotions Policy 2023）；
- 避免频繁更改价格，影响排名；
- 促销期间需保持库存充足，避免缺货。
