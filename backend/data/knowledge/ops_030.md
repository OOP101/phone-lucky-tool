# 侵权投诉与 DMCA 通知应对

## 什么是 DMCA 通知？
DMCA（Digital Millennium Copyright Act）是美国法律，用于保护数字版权。当卖家收到 DMCA 通知时，表示其产品可能侵犯了他人的版权。

## 应对步骤
1. **确认侵权内容**：查看通知中提到的具体侵权图片、描述或链接。
2. **核实是否真实侵权**：检查产品描述、图片、品牌是否确实存在侵权。
3. **提交反驳声明**：在 14 天内向亚马逊提交反驳信，说明理由。
4. **准备证据材料**：如原创设计图、授权书、商标注册证明等。

## 常见回应方式
| 回应类型 | 适用情况 |
|----------|----------|
| 无侵权 | 产品为原创设计 |
| 已获授权 | 提供授权书 |
| 侵权已修改 | 已删除侵权内容 |

## 申诉建议
- 保持冷静，避免直接否认，先核实事实。
- 保留所有设计、生产、销售记录。
- 若频繁收到投诉，建议进行版权检索并注册商标。
