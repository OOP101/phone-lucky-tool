# 体积重计算与计费重规则

## 体积重的定义与计算方式
体积重（Volumetric Weight）是物流公司在运输过程中用于计算运费的重要指标，尤其适用于轻泡货物。其计算公式为：

```
体积重 = 长 × 宽 × 高（单位：cm） ÷ 6000
```

例如：一个尺寸为 50cm × 40cm × 30cm 的包裹，体积重为 (50×40×30)/6000 = 10kg。

## 计费重的确定标准
物流公司通常以实际重量和体积重中较大的值作为计费重。根据国际航空运输协会（IATA）规定，计费重的最小单位为 0.5kg，不足 0.5kg 按 0.5kg 计算。

| 实际重量 | 体积重 | 计费重 |
|----------|--------|--------|
| 8kg     | 10kg   | 10kg   |
| 12kg    | 9kg    | 12kg   |
| 7kg     | 6kg    | 7kg    |

## 如何优化物流成本
1. **合理包装**：减少不必要的填充物，避免体积过大；
2. **选择合适物流渠道**：如 DHL、UPS 等对体积重有不同计算规则，需提前确认；
3. **使用标准化包装**：便于批量发货，降低单位成本；
4. **关注平台政策**：如亚马逊 FBA 对体积重有额外收费，需提前规划。

## 常见错误与注意事项
- 忽略体积重导致运费过高；
- 包装不规范造成体积重增加；
- 未了解不同物流商的计费规则。

## 建议操作流程
1. 产品发货前测量尺寸并计算体积重；
2. 与物流商确认计费规则；
3. 评估是否需要调整包装或选择其他物流方案；
4. 在订单系统中记录体积重信息，便于后续核算。
