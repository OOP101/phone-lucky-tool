# 差评、纠纷升级与平台介入处理

## 差评应对策略
- 1小时内回复买家，表达歉意并解释原因；
- 提供解决方案，如退款、换货或补偿；
- 鼓励买家修改评价，但不可诱导。

## 纠纷升级流程
1. 买家发起投诉；
2. 平台介入调查；
3. 双方提交证据；
4. 平台做出裁决；
5. 结果公示。

## 平台介入条件
- 买家提供有效证据（如聊天记录、照片）；
- 卖家未及时响应或处理不当；
- 商品存在明显质量问题。

## 处理时间
- 平台应在3个工作日内完成初步调查；
- 最终裁决应在7个工作日内完成。

## 注意事项
- 保持专业态度，避免情绪化回应；
- 保留所有沟通记录；
- 避免与买家私下交易，防止被平台处罚。
