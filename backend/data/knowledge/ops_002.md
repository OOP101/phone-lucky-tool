# 亚马逊账号注册资料与防关联

## 一、基础注册资料清单

注册亚马逊卖家账户时，需提供以下资料：

1. 公司营业执照或个体工商户营业执照
2. 法人身份证正反面扫描件
3. 银行账户信息（需为公司名义）
4. 企业邮箱（推荐使用Gmail或Outlook）
5. 产品类目与品牌信息（如已注册品牌）

## 二、防关联措施

为避免因IP地址、设备或网络环境相似导致账号被关联，建议采取以下措施：

1. 使用独立的物理设备（如电脑、手机）注册不同账号
2. 采用不同的网络环境（如家庭宽带、移动热点、虚拟专用网络）
3. 避免在同一时间注册多个账号
4. 使用不同的浏览器与浏览器插件（如Chrome、Firefox）

## 三、常见问题与解决方案

- **IP被封**：更换IP或使用代理服务器
- **设备被识别**：清理浏览器缓存或重装系统
- **账号被关联**：等待7天后重新注册

## 四、注意事项

- 不得使用同一手机号、邮箱或银行卡注册多个账号
- 建议使用专业防关联工具（如Zooguard、Scrapebox）
- 注册完成后，立即修改密码并启用双重验证（2FA）
