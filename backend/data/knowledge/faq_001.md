# 现货订单处理时效与发货流程

## 一、现货订单处理时效
根据平台规则，现货订单需在买家付款后 **24 小时内** 完成发货。若超过该时间未发货，系统将自动判定为“延迟发货”，可能导致店铺评分下降或处罚。

## 二、发货流程步骤
1. **订单确认**：收到订单后，需在 **2 小时内** 完成订单信息核对（包括商品、数量、地址等）。
2. **打包准备**：根据商品特性进行分类打包，确保包装牢固且符合运输要求。
3. **物流选择**：根据买家所在地区及商品重量选择合适的物流方式，如 DHL、FedEx、UPS 或本地快递。
4. **发货操作**：完成打包后，在系统中填写物流单号并提交，确保物流信息准确无误。
5. **通知买家**：发货后 **1 小时内** 向买家发送发货通知，包含物流单号和预计到达时间。

## 三、常见问题处理
- 若因库存不足导致无法按时发货，需在 **1 小时内** 联系买家协商换货或退款。
- 若物流异常，需在 **24 小时内** 提交物流追踪信息，并向买家说明情况。

## 四、关键时间节点清单
| 步骤 | 时间限制 |
|------|----------|
| 订单确认 | ≤ 2 小时 |
| 发货操作 | ≤ 24 小时 |
| 通知买家 | ≤ 1 小时 |
| 物流异常处理 | ≤ 24 小时 |
