# 破损与丢件的保险理赔流程

## 保险覆盖范围
建议为高价值商品投保，保额不低于商品售价的120%。保险涵盖：
- 运输途中破损；
- 丢失；
- 错发/漏发。

## 理赔步骤
1. 买家拍照取证并联系客服；
2. 平台审核并启动理赔流程；
3. 保险公司评估损失；
4. 确认赔付金额；
5. 完成赔付或换货。

## 材料清单
| 材料名称 | 说明 |
|---------|------|
| 订单截图 | 显示商品信息和价格 |
| 损坏照片 | 清晰显示破损部位 |
| 物流信息 | 包含物流单号和状态 |
| 身份证明 | 用于身份验证 |

## 时间限制
- 买家需在签收后7日内提出索赔；
- 平台应在10个工作日内完成初步审核；
- 保险公司应在15个工作日内完成赔付。

## 注意事项
- 保留所有物流和沟通记录；
- 避免自行维修或更换部件；
- 优先选择有保险服务的物流商。
