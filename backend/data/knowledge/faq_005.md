# 物流单号获取与在途追踪方法

## 一、物流单号获取方式
- **平台自动分配**：商家在发货后，系统会自动生成物流单号并同步至订单详情页。
- **手动录入**：若使用第三方物流，需在平台“物流管理”中手动输入物流单号。

## 二、物流单号验证标准
- 单号格式需符合物流公司要求（如 DHL 单号为 13 位数字）。
- 单号需与实际发货一致，避免错发或漏发。

## 三、在途追踪方法
1. **平台追踪**：通过平台后台“物流跟踪”功能查看实时物流状态。
2. **物流公司官网**：输入物流单号访问对应物流公司官网进行查询。
3. **API 接口**：使用平台提供的 API 接口实现自动化物流追踪。

## 四、物流异常处理
- 若物流信息长时间未更新，需联系物流公司核实情况。
- 若物流信息显示异常（如丢件、延误），需在 **24 小时内** 向买家说明并提供解决方案。

## 五、物流信息更新频率
| 物流公司 | 更新频率 |
|----------|----------|
| DHL     | 每小时一次 |
| FedEx   | 每小时一次 |
| UPS     | 每小时一次 |
| 本地快递 | 每天一次 |
