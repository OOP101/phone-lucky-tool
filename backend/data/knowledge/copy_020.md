# Facebook 广告文案结构

## 核心结构与要素
Facebook 广告文案应包含以下关键部分：标题、副标题、正文、行动号召（CTA）、附加信息（如价格、优惠码）。

## 内容分层与优化
1. **标题**：简短有力，突出卖点（如“限时折扣！最高立减 50%”）
2. **副标题**：补充说明（如“仅限黑五期间”）
3. **正文**：详细描述产品优势、适用人群、使用场景
4. **CTA**：明确引导用户点击（如“立即购买”、“查看详情”）
5. **附加信息**：包括价格、优惠码、配送信息等

## 示例文案
```
📌 标题：【黑五特惠】最高立减 50%！

📝 副标题：限时抢购，仅限 11 月 22 日 - 29 日

💬 正文：我们的智能手环现在只需 ¥99！专为运动爱好者设计，支持心率监测、睡眠分析等功能。适合健身、日常佩戴，性价比超高。

👉 CTA：立即购买

💰 附加信息：¥99 | 优惠码：BLACKFRIDAY10 | 免运费
```

## 注意事项
- 文案需符合 Facebook 广告政策（如禁止虚假宣传）
- 优化关键词，提高广告匹配度
- 定期测试不同版本，提升点击率与转化率
