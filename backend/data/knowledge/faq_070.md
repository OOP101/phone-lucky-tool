# FBA 库存移除、弃置与清算

## 1. 库存移除方式

当库存滞销或无法继续销售时，卖家可通过以下方式移除FBA库存：

- **正常退货**：通过亚马逊后台申请退货，适用于可退商品；
- **库存移除服务**：亚马逊提供付费移除服务，适用于无法退货的商品；
- **自提服务**：卖家可安排物流公司将货物从仓库提取，适用于大量库存。

## 2. 弃置与清算流程

- **弃置商品**：若商品无法销售，可申请弃置，但需支付一定费用；
- **清算商品**：通过亚马逊清算渠道出售滞销品，可获得部分回款；
- **处理时限**：亚马逊通常会在收到申请后5-10个工作日内处理。

## 3. 注意事项与成本估算

- **费用明细**：不同处理方式费用差异较大，例如：
  | 处理方式 | 费用范围（美元/件） |
  |----------|---------------------|
  | 正常退货 | $0.5 - $1.5 |
  | 清算 | $0.3 - $1.0 |
  | 弃置 | $1.0 - $3.0 |

- **库存状态更新**：处理完成后，系统会自动更新库存状态；
- **税务处理**：弃置或清算可能涉及税务申报，需提前咨询财务人员。

建议卖家定期清理滞销库存，避免仓储费用过高，同时关注亚马逊最新政策变化，以便及时调整库存策略。
