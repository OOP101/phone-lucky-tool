# 报价单的构成与报价有效期

## 一、报价单基本要素
报价单应包含以下内容：
1. 产品名称与规格；
2. 单价与总价；
3. 最小起订量（MOQ）；
4. 付款方式；
5. 交货时间与运输方式；
6. 售后服务条款。

## 二、报价有效期设定
- 一般报价有效期为 **7-15 天**，视行业惯例而定；
- 若涉及原材料价格波动较大，建议设置 **3-7 天** 的短期有效期；
- 报价单上需明确标注 **“报价有效期至 YYYY-MM-DD”**。

## 三、报价更新与变更规则
- 若客户在有效期内未确认订单，需重新报价；
- 若产品或原材料价格变动超过 **5%**，需重新评估报价；
- 保留历史报价记录，便于后期对账与争议处理。

## 四、报价单模板示例
```
[公司名称]
[地址] | [电话] | [邮箱]

报价单编号：XXXXX
日期：YYYY-MM-DD

产品名称：XXX
规格：XXX
单价：XXX 元/件
数量：XXX 件
总价：XXX 元

付款方式：银行转账
交货时间：XX 工作日
报价有效期至：YYYY-MM-DD
```

## 五、注意事项
- 报价单需加盖公章或电子签章；
- 与客户确认报价细节后再发送正式报价单；
- 定期更新报价单格式，确保信息清晰易读。
