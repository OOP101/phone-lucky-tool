# 亚马逊开店资料、注册流程与审核

## 注册所需资料

注册亚马逊卖家账户需准备以下资料：

- 公司营业执照（需为有效期内）
- 法人身份证或护照（如为外籍公司）
- 银行账户信息（需支持国际结算）
- 产品类目相关资质（如3C类需提供CCC认证）
- 企业邮箱（建议使用专业域名）

## 注册流程

1. 访问亚马逊卖家中心官网，点击“开始”进入注册页面。
2. 填写公司信息、法人信息及联系人信息。
3. 选择销售计划（个人或专业）。
4. 提交资料并等待审核。
5. 审核通过后，设置账户密码并完成初始配置。

## 审核时间与注意事项

- 审核时间通常为1-3个工作日，部分特殊类目可能延长至5个工作日。
- 审核失败时，系统会发送邮件说明原因，需根据提示补充材料。
- 注意避免提交虚假信息，否则将被永久封禁。

## 常见问题清单

| 问题 | 解决方案 |
|------|----------|
| 营业执照过期 | 更新后重新提交 |
| 银行信息不符 | 确认账户名称与营业执照一致 |
| 无法登录 | 检查邮箱是否正确，重置密码 |
| 类目不匹配 | 选择正确的商品分类 |

## 后续操作建议

- 注册完成后，尽快完成店铺设置，包括品牌备案、物流配置等。
- 开始上架产品前，确保所有资料完整且符合平台规则。
