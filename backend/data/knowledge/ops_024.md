# 库存周转与滞销库存清理

## 1. 库存周转率的计算与目标
库存周转率 = 销售额 / 平均库存价值。根据行业标准，理想周转率应在4-6次/年。

- 高周转率：资金利用率高，减少仓储成本
- 低周转率：库存积压，增加运营风险

## 2. 滞销库存的识别与处理
滞销库存是指超过90天未售出的商品。根据《亚马逊FBA政策》第5.2条，滞销库存可能产生高额仓储费用。

- 识别方法：定期查看库存报告，筛选长期未动销商品
- 处理方式：降价促销、捆绑销售、移除至海外仓

## 3. 清理滞销库存的建议
清理滞销库存需要结合市场分析与促销策略。

- 制定促销计划，设置折扣或赠品
- 利用站内广告提升曝光
- 评估是否适合转为海外仓库存
