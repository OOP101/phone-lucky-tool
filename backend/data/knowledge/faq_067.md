# Review 评论政策与 Vine 计划

## 1. Review 评论政策概述

亚马逊等平台对Review评论有严格的管理规则，旨在防止虚假评价，保障买家权益。卖家需遵守以下条款：

- **禁止诱导好评**：不得以任何形式（如赠品、折扣、优惠券）诱导买家撰写正面评论（条款：Amazon A-to-Z Guarantee Policy, Section 5.2）。
- **禁止删除差评**：不得通过任何方式要求买家修改或删除负面评论。
- **禁止刷评行为**：不得雇佣第三方进行虚假评论。

违反上述规定可能导致账号受限甚至封禁。

## 2. Vine 计划介绍

Vine 是亚马逊推出的官方邀请机制，允许品牌向特定用户免费提供产品，以获取真实评论。该计划适用于已注册品牌备案的卖家。

- **申请条件**：需完成品牌备案（Brand Registry），且产品符合平台审核标准。
- **操作流程**：
  1. 登录 Brand Registry 页面，提交申请；
  2. 等待亚马逊审核，通常需1-3个工作日；
  3. 审核通过后，可邀请符合条件的Vine用户试用产品并撰写评论。

## 3. 评论管理建议

- **鼓励真实反馈**：通过优质服务和产品吸引自然评论；
- **及时处理差评**：主动联系买家解决问题，争取修改或删除差评；
- **利用 Vine 获取高质量评论**：提升产品可信度和转化率。

建议每月至少检查一次Review情况，并根据反馈优化产品和服务。
