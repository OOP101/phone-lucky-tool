# 带电产品可走的物流渠道

## 一、主流物流渠道分类

带电产品（含电池）可选择以下物流渠道：

- **空运（Air Freight）**：速度快，适合高价值或紧急订单。
- **海运（Sea Freight）**：成本低，适合大批量货物。
- **快递（Express）**：如DHL、UPS、FedEx，支持带电产品，但费用较高。
- **专线物流（Specialized Logistics）**：如顺丰、燕文等，针对带电产品优化。

## 二、各渠道限制与要求

| 渠道       | 是否允许带电产品 | 限制条件                         |
|------------|------------------|----------------------------------|
| 空运       | 是               | 需符合IATA危险品运输规定         |
| 海运       | 是               | 需通过UN38.3测试，包装合规       |
| 快递       | 是               | 需提供电池类型说明，部分品牌限制 |
| 专线物流   | 是               | 通常有专门的带电产品运输方案     |

## 三、操作建议

1. 选择物流商前，确认其是否具备带电产品运输资质。
2. 准备UN38.3测试报告、MSDS文件等必要资料。
3. 优先选择有带电产品运输经验的物流商，如《危险品运输管理条例》第6条。

## 四、注意事项

- 不同渠道对电池容量、数量、包装要求不同，需逐一核实。
- 避免使用普通物流渠道运输带电产品，以免被拒收或罚款。
