# 打样周期、样品确认与封样

## 样品打样周期
根据行业标准，一般打样周期为3-7个工作日。具体时间需根据产品复杂度和供应商产能而定。例如：

| 产品类型 | 打样周期 |
|----------|-----------|
| 简单产品 | 3-5天 |
| 复杂产品 | 5-7天 |
| 定制产品 | 7-10天 |

建议在下单前明确打样周期，并在合同中注明。

## 样品确认流程
样品确认需遵循以下步骤：

1. 供应商提供样品后，买家需在24小时内进行初步检查；
2. 检查内容包括外观、尺寸、材质、功能等；
3. 若有问题，需在48小时内反馈并要求修改；
4. 修改后再次提交样品，直至双方确认无误。

## 封样要求
封样是确保批量生产一致性的关键环节，需注意以下几点：

- 封样需由买卖双方共同完成，并签署《封样确认书》；
- 封样样品应包含所有关键部件及包装；
- 封样后需妥善保存至少12个月，以备后续质量争议时使用；
- 建议对封样样品进行拍照并存档。

## 样品管理建议
- 建立样品管理制度，记录每一批次的样品信息；
- 对于高频次采购的产品，可建立长期合作样品库；
- 避免因样品不一致导致客户投诉或退货。

## 法规与条款参考
- 《中华人民共和国产品质量法》第26条：生产者应当对其生产的产品质量负责；
- 国际贸易中，依据《国际贸易术语解释通则》（INCOTERMS® 2020）中的“EXW”条款，买方需自行承担样品运输风险。
