# 亚马逊二审、KYC 与视频验证

## 二审流程概述

亚马逊二审是针对企业账户的进一步身份核实，通常在首次注册后1-2周内触发。主要目的是验证企业真实性和合法性。

## KYC 身份验证

KYC（Know Your Customer）要求提供以下内容：

- 公司注册证明（如公司章程、股东信息）
- 法人身份证明（身份证或护照）
- 银行对账单（需显示公司名称）
- 企业税务登记证（如适用）

## 视频验证步骤

1. 登录卖家中心，进入“Account Information”页面。
2. 点击“Video Verification”按钮，按提示录制视频。
3. 视频中需展示公司地址、法人证件及营业执照。
4. 提交后等待审核，通常需1-3个工作日。

## 常见拒绝原因

| 原因 | 说明 |
|------|------|
| 视频不清晰 | 确保光线充足，画面清晰 |
| 信息不一致 | 确认所有文件信息一致 |
| 材料缺失 | 补充缺失文件后再提交 |

## 注意事项

- 视频验证需由法人亲自操作，不可代为录制。
- 所有材料必须为英文或中文，非中文材料需提供翻译件。
- 若多次审核失败，可联系亚马逊客服获取帮助。
