# 丢件破损索赔的证据链

## 索赔前准备
在发生丢件或破损时，卖家需立即收集以下证据：

- **物流轨迹截图**：显示货物状态及异常节点
- **商品照片**：拍摄包裹外包装及内部物品损坏情况
- **买家反馈记录**：包括聊天记录、邮件、投诉平台截图等
- **发票与订单详情**：证明商品价值与购买信息

## 证据链构成
有效的索赔需满足以下要素：

1. **物流责任明确**：通过物流轨迹判断是哪个环节导致问题
2. **损失金额合理**：根据订单金额与实际损失确定赔偿额度
3. **时间线清晰**：从发货到发现异常的时间段需完整记录
4. **多方确认**：买家、卖家、货代三方均需参与确认

## 索赔流程
1. **提交索赔申请**：通过平台或货代系统填写表单并上传证据
2. **等待审核**：货代通常在3-7个工作日内完成审核
3. **协商赔偿**：根据条款约定达成赔偿方案
4. **执行赔付**：货代按协议支付赔偿金

## 法规与条款参考
- 《国际货运代理服务标准》第12条：明确货代对货物安全的责任
- 《跨境电子商务平台服务协议》第9.3条：规定卖家索赔流程
- 《国际贸易术语解释通则》（INCOTERMS）：界定责任划分

## 风险防范建议
- 为高价值商品投保额外险种（如DHL附加险）
- 在包裹上标注“易碎品”或“贵重物品”提示
- 选择有良好理赔记录的物流服务商
