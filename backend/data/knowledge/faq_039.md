# 加州 65 号提案警示要求

## 法规背景与适用范围
加州《1986年安全饮用水与有毒物质管制法》（Proposition 65, Cal. Health & Saf. Code §25249.7）要求企业在产品中若含有已知致癌物或生殖毒性物质，必须提供明确警示。该法规适用于所有在加州销售的产品，包括电子产品、玩具、服装等。

## 警示要求与内容
企业需在产品包装、说明书或网站上注明：“WARNING: This product contains chemicals known to the State of California to cause cancer and/or birth defects.” 此外，若产品含有铅、邻苯二甲酸盐等物质，需额外标注具体成分名称。

## 合规流程与步骤
1. **识别有害物质**：通过供应商或测试报告确认产品成分。
2. **评估风险**：判断是否超过Prop 65限值。
3. **制定警示内容**：按法规要求撰写警示语。
4. **更新产品信息**：在包装、网页、说明书上添加警示。
5. **保留记录**：保存测试报告与警示文本。

## 常见问题与建议
- 即使产品未直接销售至加州，也需考虑合规。
- 若产品含铅量低于0.001%（10ppm），可免于警示。
- 建议与供应商合作，确保原材料合规。

## 表格：Prop 65常见物质与限值
| 物质 | 限值 |
|------|------|
| 铅 | 0.001% (10ppm) |
| 邻苯二甲酸盐 | 0.1% |
| 甲醛 | 0.01ppm |
| 多环芳烃 | 0.0001% |
| 重金属（如镉、汞） | 0.0001% |
