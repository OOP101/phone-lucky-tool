# 欧盟 CE 标志制度总览

CE 标志是欧盟市场对产品进入的强制性认证标志，代表产品符合欧盟相关法规要求。对于中国跨境电商卖家而言，了解 CE 标志的适用范围和申请流程至关重要。

## CE 标志的适用范围

CE 标志适用于以下产品类别：
- 电子电气设备（如手机、电脑）
- 玩具与儿童用品
- 机械设备
- 建筑材料
- 医疗器械

根据《欧盟指令 2005/36/EC》，所有进入欧盟市场的商品需通过 CE 认证，否则将被禁止销售。

## CE 标志的申请流程

1. **确定产品分类**：依据产品类型选择对应的欧盟协调标准（如 EN 60950-1 用于 IT 设备）。
2. **进行合规测试**：委托欧盟认可的第三方检测机构（如 TÜV、SGS）进行测试。
3. **起草技术文件**：包括产品设计图纸、使用说明书、测试报告等。
4. **签署符合性声明**：由制造商或授权代表签署，并附上 CE 标志。
5. **加贴 CE 标志**：在产品包装或本体上清晰标注 CE 标志。

## CE 标志的常见问题

| 问题 | 回答 |
|------|------|
| 是否需要每年更新？ | 不需要，但需持续满足法规要求 |
| 可否自行贴标？ | 不可，必须由授权代表或制造商完成 |
| 是否有罚款风险？ | 是，违规可能面临最高 20 万欧元罚款 |
