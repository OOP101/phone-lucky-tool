# 墨西哥 NOM 强制认证

## 一、NOM 认证概述
墨西哥国家标准化与认证研究所（IMC）负责管理NOM（Norma Oficial Mexicana）认证，适用于电子产品、医疗器械、化学品等。根据《墨西哥联邦法规》第19条，部分产品必须通过NOM认证后方可进口和销售。

目前，超过200种产品被列入NOM强制认证清单，涵盖家电、汽车配件、儿童用品等。

## 二、NOM 认证流程
1. **申请准备**：提交企业资质、产品技术文档、测试报告等。
2. **样品送检**：送至墨西哥认证机构（如DGN）进行测试。
3. **工厂审查**：认证机构对生产工厂进行现场审核。
4. **证书颁发**：通过审核后，获得NOM认证证书。
5. **持续监督**：每年需提交年审报告，确保产品符合标准。

## 三、NOM 认证分类
NOM认证分为以下几类：
- **强制认证（Mandatory）**：如电动工具、电池、照明设备等。
- **自愿认证（Voluntary）**：如部分日用百货、包装材料。
- **自我声明（Self-declaration）**：适用于低风险产品。

## 四、常见问题与应对策略
| 问题 | 解决方案 |
|------|----------|
| 认证周期长 | 提前规划，选择有经验的代理机构 |
| 测试费用高 | 选择性价比高的实验室 |
| 认证类型不清 | 明确产品类别，咨询专业机构 |

## 五、合规建议
- 确认产品是否属于NOM强制认证目录
- 选择权威的认证机构
- 保持与认证机构的沟通，及时更新产品信息
