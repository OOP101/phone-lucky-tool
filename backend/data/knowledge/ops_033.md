# BSR 畅销榜排名机制

## BSR 简介
BSR（Best Seller Rank）是亚马逊根据销量、转化率、点击率等数据生成的排名系统，用于展示某一类目下的热销商品。BSR排名分为两个层级：
- 全站排名（Global Rank）；
- 类目排名（Category Rank）。

## 排名影响因素
BSR排名主要受以下因素影响：
- 销量（占比约60%）；
- 价格（与同类产品相比）；
- 评论数量与评分（占比约20%）；
- 商品信息完整性（如标题、五点描述、图片）；
- 广告投放效果（如Sponsored Products）。

## 提升排名的策略
| 策略 | 说明 |
|------|------|
| 优化标题与关键词 | 提高搜索可见性 |
| 提高转化率 | 优化图片与描述 |
| 增加销量 | 通过促销活动或广告 |
| 提升评分 | 改善产品质量与服务 |
| 使用广告 | 提高曝光率 |

## 注意事项
- 不得通过刷单提升排名；
- 不得伪造销量数据；
- 避免频繁更改价格或库存；
- 定期查看BSR变化趋势，调整运营策略。
