# Buy Box 购物车竞争机制

## Buy Box 获取规则
Buy Box 是亚马逊首页展示的“立即购买”按钮，获取条件包括：
- 价格竞争力（低于或等于竞品）
- 评分高于 4 星（含）
- 库存充足（至少 1 件）
- 退货率低于 10%
- 无违规记录（如假货、差评）

## 竞争策略
1. **价格优化**：保持价格优势，可略低于竞品 1-2 美元。
2. **评分提升**：鼓励买家留下好评，可使用 FBA 提升物流体验。
3. **库存管理**：确保库存稳定，避免缺货导致 Buy Box 流失。
4. **FBA 优先**：使用亚马逊物流可提高信任度，增加 Buy Box 机会。

## 丢失 Buy Box 的常见原因
| 原因 | 描述 |
|------|------|
| 价格过高 | 低于竞品 5 美元以上 |
| 评分低 | 低于 4 星 |
| 缺货 | 库存为零 |
| 退货率高 | 超过 10% |
| 违规 | 有投诉或封禁记录 |

## 提升 Buy Box 机会的建议
1. 保持价格竞争力，定期比对竞品。
2. 提升产品质量与服务，提高评分。
3. 使用 FBA 提升物流效率。
4. 优化产品页面，提高转化率。
5. 监控竞品活动，及时调整策略。
