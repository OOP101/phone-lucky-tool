# 旺季促销社交媒体文案

## 文案目标与受众
旺季促销文案的目标是吸引潜在客户，提高转化率。主要面向关注节日、打折活动的消费者。

## 关键要素与结构
1. **标题**：吸引眼球，如“【限时抢购】黑五特惠，最高立减 50%！”
2. **正文内容**：
   - 强调促销时间（如 Black Friday、Cyber Monday）
   - 列出主打产品及折扣力度
   - 提供优惠码或链接
   - 增加紧迫感（如“仅限前 100 名”）
3. **标签**：添加相关话题标签（如 #BlackFriday, #CyberMonday）

## 示例文案
```
🎉【限时抢购】黑五特惠，最高立减 50%！🎉

🔥 11 月 22 日 - 29 日，全场商品限时折扣！

🛒 推荐产品：
- 无线耳机：原价 ¥299 → 现价 ¥149（立减 50%）
- 智能手环：原价 ¥199 → 现价 ¥99（立减 50%）

🎁 优惠码：BLACKFRIDAY10

⏰ 仅限前 100 名下单用户！

#BlackFriday #CyberMonday #跨境电商 #限时折扣
```

## 注意事项
- 文案需符合平台规范（如 Facebook、Instagram）
- 图文结合，提升吸引力
- 定期更新内容，保持热度
