# 出口信用保险投保与外贸坏账追偿流程

## 一、投保流程
出口信用保险是防范海外买家违约风险的重要工具，适用于中国出口企业。

1. 选择保险公司（如中国信保）并提交申请表。
2. 提供出口合同、发票、运输单据等文件。
3. 保险公司评估风险后出具保单。
4. 缴纳保费，通常按出口额的 0.5%-1.5% 计算。

## 二、理赔流程

当买家无法付款时，可向保险公司申请赔偿。

1. 发现买家违约后，立即通知保险公司。
2. 提交相关证据，如信用报告、付款凭证、沟通记录等。
3. 保险公司进行调查并确认是否符合赔付条件。
4. 审核通过后，保险公司将在 15-30 个工作日内支付赔款。

## 三、追偿流程

若保险公司赔付后仍可追回款项，可继续追偿。

1. 保险公司协助提供法律支持，如律师函、诉讼等。
2. 通过外交途径或国际仲裁机构进行追偿。
3. 追偿成功后，保险公司将返还部分赔款。

## 四、注意事项
- 投保前需了解保险条款，特别是免责条款（如战争、政治风险等）。
- 定期跟踪买家信用状况，避免高风险交易。
- 保留完整交易记录，以便后续理赔与追偿使用。
