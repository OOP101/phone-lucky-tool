# 关税预缴（DDP）与到付（DDU）的区别

## 定义与适用场景
- **DDP（Delivered Duty Paid）**：卖方承担全部运输、保险、关税和清关费用，适用于买家希望完全无忧收货的情况。
- **DDU（Delivered Duty Unpaid）**：卖方负责运输至目的地，但不承担关税和清关费用，由买方自行处理。

## 费用对比
| 项目 | DDP | DDU |
|------|-----|-----|
| 运输费用 | 包含 | 包含 |
| 保险费用 | 包含 | 包含 |
| 关税 | 包含 | 不包含 |
| 清关费用 | 包含 | 不包含 |
| 附加费用 | 可能有 | 无 |

## 选择建议
- 若买家对清关流程不熟悉，推荐使用 DDP。
- 若买家具备清关能力且希望控制成本，可选择 DDU。

## 风险提示
- DDP 风险主要在于卖方需承担额外成本，可能影响利润。
- DDU 风险在于买方可能因不了解清关规则导致延误或罚款。

## 实操建议
- 明确合同条款，避免模糊表述。
- 与物流商确认具体费用结构，避免后期纠纷。
- 根据客户背景灵活选择贸易术语。
