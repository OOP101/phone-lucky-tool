# 欧盟化妆品法规 EC 1223/2009 与 CPNP
## 法规概述
EC 1223/2009 是欧盟化妆品法规，规定了化妆品的安全性、标签和广告要求。CPNP（Cosmetic Products Notification Portal）是化妆品通知平台，用于注册和通报化妆品信息。

## 注册流程
1. **建立企业账户**：在CPNP官网注册企业账号。
2. **填写产品信息**：包括成分、用途、包装、安全评估等。
3. **提交至成员国**：选择一个欧盟成员国进行注册。
4. **获取注册编号**：成功后获得CPNP注册号。

## 成分限制
- 禁止使用物质：如某些重金属、致敏香料（条款14）
- 限用物质：如防腐剂、防晒剂（条款15）
- 标签要求：必须注明成分列表（INCI名称）

## 常见问题
| 问题 | 回答 |
|------|------|
| 是否需要安全评估？ | 是，必须由合格专家完成 |
| 是否需要CPNP注册？ | 是，所有进入欧盟市场的化妆品 |
| 注册费用？ | 免费，但需支付公告机构费用 |

## 注意事项
- 严格遵守成分清单，避免违规
- 定期更新产品信息，保持合规性
