# 阶梯报价、账期与付款方式谈判

## 一、阶梯报价机制
阶梯报价是指随着订单数量增加，单价逐步下降。例如：
| 订单量 | 单价（元/件） |
|--------|------------------|
| 100-500 | 10.00 |
| 501-1000 | 9.50 |
| >1000 | 9.00 |

## 二、账期与付款方式
- **账期**：指从发货到收款的时间，一般为 **30-90 天**；
- **付款方式**：常见为 **预付 30% + 尾款 70%**，也可协商 **信用证（L/C）** 或 **T/T**。

## 三、谈判策略与技巧
- 提供 **阶梯报价** 以鼓励客户提高订单量；
- 对于大客户，可适当延长账期至 **90 天**；
- 若客户资金紧张，可协商 **分期付款** 或 **部分预付**；
- 优先选择 **T/T 30% 预付**，以降低风险。

## 四、注意事项
- 明确账期与付款方式，避免后期纠纷；
- 与客户确认付款时间节点，确保资金回笼；
- 对于长期合作客户，可协商 **账期优惠** 以增强粘性。

## 五、建议条款
- 合同中应注明：“若订单量超过 X 件，单价按阶梯报价执行。”
- 付款方式应明确写入合同，如：“客户需在发货前支付 30% 预付款。”
