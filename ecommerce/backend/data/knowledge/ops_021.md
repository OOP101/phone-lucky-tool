# Review 获取的合规边界

## 1. Review 获取的合法途径
根据亚马逊平台规则，卖家不得通过任何非官方渠道获取Review。根据《亚马逊卖家行为准则》第5.3条，禁止使用第三方工具或服务诱导买家撰写Review。

- 合法方式：通过亚马逊Buy Box、邮件邀请（需符合平台规定）
- 非法方式：付费购买Review、提供赠品换取Review

## 2. Review 内容的合规要求
Review内容必须真实、客观，不得包含虚假信息或误导性描述。根据《亚马逊Review政策》第3.1条，禁止发布带有广告性质的内容。

- 禁止内容：夸大产品功能、贬低竞争对手、使用不实数据
- 允许内容：真实使用体验、产品优缺点分析

## 3. Review 操作的法律风险
违规获取Review可能导致账号被封、罚款甚至法律责任。根据中国《反不正当竞争法》第8条，虚假宣传属于违法行为。

- 平台处罚：Review删除、账号限制、店铺关闭
- 法律后果：罚款、信用受损、品牌声誉影响
