# 液体、粉末等敏感货渠道

## 敏感货定义与分类
液体、粉末等货物在跨境电商物流中被归类为敏感货，主要因其易燃、易爆、腐蚀性或对运输安全构成威胁。根据《国际海运危险货物规则》（IMDG Code）第1.1.3条，此类货物需特别包装和申报。

## 常见敏感货类型
- 液体：香水、洗发水、清洁剂
- 粉末：护肤品粉、香料、肥料
- 其他：电池、磁性材料、化学制品

## 运输流程与注意事项
1. 包装需符合UN38.3标准，使用防漏容器；
2. 提交MSDS（物质安全数据表）；
3. 选择有危险品运输资质的承运商；
4. 报关时注明货物性质，避免延误。

## 合规建议
- 定期更新产品成分信息；
- 与物流公司签订专项协议；
- 参考海关总署公告2020年第75号，确保合规运输。
