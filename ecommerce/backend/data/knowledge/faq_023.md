# PayPal 外贸收款的规则与风控

## 收款流程
PayPal 是跨境电商常用的在线支付工具，适用于B2C交易。其流程如下：

1. 买家在平台下单后，通过PayPal付款；
2. 卖家收到付款通知后安排发货；
3. 买家确认收货后，款项自动转入卖家账户。

## 收款规则与限制
- PayPal 支持美元、欧元、英镑等多种货币；
- 单笔交易限额为$10,000（具体以账户类型为准）；
- 未实名认证账户无法接收大额款项；
- 交易费用一般为2.9% + $0.30/笔。

## 风控措施
为保障资金安全，建议采取以下措施：

- 实名认证PayPal账户，提高交易额度；
- 不接受“预付+退货”等高风险交易；
- 定期查看账户流水，及时发现异常；
- 避免使用他人账户收款，防止被封号。

## 常见问题与应对
- **账户被封**：可能是因频繁交易或涉嫌欺诈，需联系客服申诉；
- **退款纠纷**：可通过平台介入处理，保留聊天记录和交易凭证；
- **汇率损失**：建议将外币兑换为人民币，减少汇率波动影响。

## 法规与条款参考
- 根据《PayPal用户协议》第7条，禁止用于非法交易；
- 第12条规定，账户违规可能导致资金冻结或永久封禁。
