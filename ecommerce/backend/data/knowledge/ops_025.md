# FBA 移除订单与清算渠道

## 1. FBA 移除订单的适用场景
FBA移除订单适用于滞销、过期或无法继续销售的商品。根据《亚马逊FBA政策》第6.1条，卖家可申请移除库存。

- 滞销库存
- 过期或损坏商品
- 无法满足市场需求的商品

## 2. 移除订单的流程
申请FBA移除订单需按照以下步骤操作：

1. 登录卖家后台，进入“库存管理”
2. 选择需移除的SKU，提交移除请求
3. 等待系统审核，通常需3-5个工作日
4. 支付移除费用，等待货物返回

## 3. 清算渠道的选择
移除后的库存可通过以下渠道进行清算：

- 二手平台（如eBay、闲鱼）
- 海外仓转卖
- 报废处理（需符合当地环保法规）

| 清算方式 | 适用情况 | 成本 | 风险 |
|----------|----------|------|------|
| 二手平台 | 次新商品 | 低 | 中 |
| 海外仓转卖 | 大量库存 | 中 | 高 |
| 报废处理 | 损坏或过期 | 高 | 无 |
