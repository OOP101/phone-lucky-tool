# 账户健康度（Account Health）指标体系

## 一、核心指标解析

亚马逊账户健康度由以下四个关键指标构成：

1. **订单缺陷率（Order Defect Rate）**：包含负面反馈、退款率和A-to-Z索赔率，标准值应低于1%。
2. **有效跟踪率（Effective Tracking Rate）**：订单发货后必须在24小时内上传跟踪信息，否则视为未跟踪。
3. **延迟发货率（Late Shipment Rate）**：订单应在承诺时间内发货，延迟发货率不得超过2%。
4. **取消率（Cancellation Rate）**：订单取消率不得超过2.5%。

## 二、健康度评分规则

亚马逊对账户健康度进行评级，分为“良好”、“中等”和“差”三个等级。若连续30天健康度低于80分，可能面临账户限制。

## 三、优化建议

- 定期检查订单状态，确保及时发货与更新跟踪信息
- 提供优质的客户服务，减少负面反馈与A-to-Z索赔
- 优化库存管理，避免缺货或超卖情况
- 定期查看亚马逊通知中心，及时处理违规事项

## 四、异常处理流程

若账户健康度下降，需立即采取以下步骤：

1. 登录卖家平台，查看具体违规原因
2. 根据提示整改，如补发货物、联系买家协商退货
3. 提交申诉材料至亚马逊审核
4. 保持账户活跃，避免长时间不操作
