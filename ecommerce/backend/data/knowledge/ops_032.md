# Test Buy 与差评处理的合规边界

## Test Buy 的定义与用途
Test Buy 是亚马逊为验证卖家发货速度、包装质量等而进行的模拟购买行为，通常由亚马逊内部人员执行。卖家需注意：
- 不得主动要求Test Buy；
- 不得提供额外优惠或服务；
- 不得在Test Buy后删除差评。

## 差评处理的合规方式
根据《亚马逊卖家政策》第9.5条，差评处理应遵循以下原则：
- 不得通过任何方式诱导买家修改评价；
- 不得对差评进行公开回应或威胁；
- 可通过私信沟通解决客户问题。

## 常见违规行为清单
| 违规行为 | 处罚后果 |
|----------|-----------|
| 诱导好评 | 列表下架、账号封禁 |
| 删除差评 | 列表下架、账号封禁 |
| 未及时响应差评 | 评分下降、流量减少 |
| 通过第三方平台刷单 | 账号永久封禁 |

## 合规建议
- 建立完善的售后服务流程；
- 定期分析差评内容并优化产品；
- 避免使用第三方刷单工具；
- 如遇恶意差评，可通过亚马逊官方渠道申诉。
