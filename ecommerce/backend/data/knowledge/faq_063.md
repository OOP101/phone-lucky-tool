# Listing 上架被拒的常见原因

## 侵权问题

- 未获得品牌授权：若使用品牌商标，需先进行品牌备案。
- 重复Listing：同一产品不得重复上架，需合并或修改。
- 侵权图片：使用他人版权图片可能导致下架。

## 信息不完整

- 缺少必要属性：如尺寸、重量、材质等字段未填写。
- 产品描述不清晰：需用中文或英文详细描述功能与用途。
- 无明确用途说明：如电子产品需注明适用场景。

## 违规类目

- 错误分类：如将服装归入电子类目。
- 不允许销售的商品：如仿冒品、违禁品等。
- 未提供合规证书：如3C、FDA、CE等。

## 常见拒绝代码与解决方法

| 拒绝代码 | 说明 | 解决方法 |
|----------|------|----------|
| 1001 | 侵权 | 提交品牌备案或删除侵权内容 |
| 1002 | 信息不全 | 补充缺失字段 |
| 1003 | 分类错误 | 修正商品分类 |
| 1004 | 违规商品 | 删除或更换商品 |

## 优化建议

- 使用亚马逊提供的产品模板，确保格式正确。
- 在发布前使用“Check for Issues”工具检查Listing。
- 如被拒，根据系统提示及时修改并重新提交。
