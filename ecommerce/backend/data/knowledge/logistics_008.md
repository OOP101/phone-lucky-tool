# 欧洲卡航派送渠道

## 卡航定义与适用场景
卡航（Truck Transport）是指通过卡车将货物从中国港口或仓库直接运送到欧洲各国的派送方式，适用于**短途、小批量、高时效需求**的订单。

## 卡航操作流程
1. **货物集港**：将货物集中至指定港口或仓库；
2. **报关与清关**：由代理完成出口报关，并在欧洲完成进口清关；
3. **车辆调度**：根据目的地分配运输车辆，通常为**4.2米或9.6米货车**；
4. **运输执行**：按计划发车，预计运输时间为**3-5天**；
5. **末端派送**：由欧洲本地配送商完成最后一公里派送。

## 卡航成本与时效参考
| 项目        | 说明                          |
|-------------|-------------------------------|
| 运输时间    | 3-5天（从中国到德国）         |
| 单位运费    | 2.5-3.5元/公斤（视距离）      |
| 最低起运量  | 100公斤以上                   |
| 时效保障    | 可选加急服务（额外收费）      |

## 优势与挑战
- **优势**：
  - 时效优于海运；
  - 成本低于空运；
  - 支持**门到门服务**；
- **挑战**：
  - 需要专业代理协调；
  - 受天气、交通影响较大；
  - 需要提前预约车辆。

## 选择卡航的注意事项
- 选择**有欧洲本地网点**的物流公司；
- 确认是否提供**清关服务**；
- 了解是否有**延迟赔付机制**；
- 对比多家报价，选择性价比高的方案。

## 总结
卡航是欧洲物流的重要补充，尤其适合**快速响应、小批量出货**的卖家。企业应结合自身需求，选择可靠的物流服务商，确保运输效率与服务质量。
