# 海运拼箱计费方式、亏舱费与注意事项

## 一、计费方式
海运拼箱按体积计费，单位为CBM（立方米）。计算公式如下：

```
体积 = 长(m) × 宽(m) × 高(m)
```

计费以实际体积或毛重（公斤）中的较大者为准，一般按1 CBM = 1000 kg 计算。

## 二、亏舱费说明
1. **定义**：若客户未按约定提供足够货物，导致船公司无法满载，需支付亏舱费。
2. **费用标准**：通常为10%-20%的运费，具体以合同条款为准。
3. **规避方法**：提前确认货物量，尽量填满仓位，避免亏舱。

## 三、常见问题与应对
- **货物不齐**：若部分货物未按时交付，可能导致亏舱费，需与货代协商调整。
- **超重或超大**：超出标准尺寸或重量，需支付附加费（如超重费、超大件费）。
- **清关风险**：拼箱货物需统一清关，若资料不全或有误，可能导致清关延误。

## 四、操作建议
1. **提前规划**：合理预估货物量，避免亏舱。
2. **资料齐全**：确保商业发票、装箱单等资料完整准确。
3. **选择可靠货代**：确保拼箱服务稳定，避免因货代问题影响时效。
