# 巴西 INMETRO 与 ANATEL 认证

## 一、INMETRO 认证概述
巴西国家计量、标准化与合格认证机构（INMETRO）负责管理INMETRO认证，适用于电子产品、家电、玩具等。根据《巴西联邦法律》第10条，部分产品必须通过INMETRO认证后方可进口和销售。

目前，超过200种产品被列入INMETRO强制认证清单，涵盖家电、IT设备、医疗设备等。

## 二、ANATEL 认证概述
ANATEL 是巴西电信管理局，负责管理电信设备的认证。根据《巴西电信法》第15条，无线设备、通信设备等必须通过ANATEL认证。

ANATEL认证主要针对：
- 移动电话
- 无线电设备
- 网络设备

## 三、认证流程对比
| 认证类型 | 流程步骤 |
|----------|----------|
| INMETRO | 申请准备 → 样品送检 → 工厂审查 → 证书颁发 |
| ANATEL | 申请准备 → 样品送检 → 电磁兼容测试 → 证书颁发 |

## 四、常见问题与应对策略
| 问题 | 解决方案 |
|------|----------|
| 认证周期长 | 提前规划，选择有经验的代理机构 |
| 测试费用高 | 选择性价比高的实验室 |
| 认证类型不清 | 明确产品类别，咨询专业机构 |

## 五、合规建议
- 确认产品是否属于INMETRO或ANATEL强制认证目录
- 选择权威的认证机构
- 保持与认证机构的沟通，及时更新产品信息
