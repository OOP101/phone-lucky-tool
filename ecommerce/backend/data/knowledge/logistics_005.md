# 国际空运操作流程与计费重计算

## 一、操作流程
1. **下单**：通过货代或航空公司平台下单，填写货物信息（品名、重量、体积）。
2. **打包与称重**：货物需按航空标准打包，称重并测量体积。
3. **交货**：将货物送至指定机场或货代仓库，支付运费。
4. **运输**：货物由航空公司运输，通常2-5天到达目的地。
5. **清关与派送**：清关后由当地代理派送至收货人地址。

## 二、计费重计算
国际空运计费重按“实际重量”与“体积重量”中的较大者计算，公式如下：

```
体积重量 = 长(cm) × 宽(cm) × 高(cm) ÷ 6000
```

例如：一个货物长60cm、宽40cm、高30cm，则体积重量为：

```
(60×40×30)/6000 = 12 CBM
```

若实际重量为10kg，则计费重为12kg（按体积计算）。

## 三、注意事项
- **货物限制**：禁止运输易燃、易爆、液体等危险品。
- **清关资料**：需提供商业发票、装箱单、提单等，确保信息一致。
- **时效保障**：选择有信誉的货代，确保准时送达。

## 四、操作建议
1. **合理打包**：减少体积，降低计费重。
2. **提前预约**：旺季时舱位紧张，建议提前1周以上预订。
3. **保险购买**：高价值货物建议购买运输保险，防范风险。
