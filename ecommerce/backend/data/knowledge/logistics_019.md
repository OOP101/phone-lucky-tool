# 关税测算方法与反倾销税

## 一、关税测算方法
关税计算公式为：

> 关税 = 税基 × 税率

其中，税基通常为货物的**CIF价格**（成本+保险+运费），税率依据HS编码确定。

### 示例：
- 货物价值：$1000
- 运费：$100
- 保险：$50
- CIF价格：$1150
- 关税税率：10%
- 应缴关税：$115

## 二、反倾销税适用情况
反倾销税适用于以下情形：

1. **进口产品以低于正常价值销售**，对本国产业造成损害。
2. **国家发起反倾销调查**，并最终裁定征收反倾销税。
3. **涉及特定国家或产品类别**，如钢铁、光伏、轮胎等。

## 三、应对策略
- **提前查询反倾销清单**：可通过中国商务部或海关总署官网查询。
- **调整定价策略**：避免因低价引发反倾销调查。
- **寻求法律支持**：如有争议，可委托律师参与申诉。
