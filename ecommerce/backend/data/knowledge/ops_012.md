# Listing 合并与僵尸 Listing 风险

## Listing 合并规则
亚马逊允许卖家合并相似 Listing，前提是满足以下条件（Policy ID: 2019-0547）：
- 共享相同 UPC/EAN
- 产品属性高度一致（如品牌、型号、功能）
- 无明显差异（如包装、配件）

## 僵尸 Listing 形成原因
1. **重复上传**：同一产品多次上传，导致多个 Listing 存在。
2. **未更新信息**：长时间未维护的 Listing 会被标记为僵尸。
3. **无效库存**：库存为零或已下架的 Listing 会被系统识别为僵尸。

## 风险与影响
- **流量分散**：多个 Listing 分散搜索排名，降低整体曝光。
- **评分稀释**：多个 Listing 的评价无法合并，影响产品信誉。
- **账户风险**：亚马逊会认为卖家存在操作行为，可能触发审核。

## 合规建议清单
1. 定期清理无效 Listing，尤其是库存为零的。
2. 使用亚马逊的“合并 Listing”功能进行统一管理。
3. 避免重复上传，确保每个 Listing 有唯一性。
4. 更新 Listing 信息，包括标题、描述、图片等。
5. 对于多语言市场，需分别管理 Listing，不可混用。

## 僵尸 Listing 处理流程
| 步骤 | 内容 |
|------|------|
| 1 | 亚马逊系统自动检测僵尸 Listing |
| 2 | 发送通知邮件给卖家 |
| 3 | 卖家需在 7 天内处理或解释 |
| 4 | 未处理 Listing 将被删除 |
| 5 | 严重情况可能影响账户状态 |
