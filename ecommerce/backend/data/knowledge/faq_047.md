# 质量异议期与索赔需要的证据

## 一、质量异议期定义
根据《中华人民共和国民法典》第 582 条，买方应在收到货物后合理期限内提出质量问题，通常为 15-30 天。

## 二、索赔所需证据清单
| 证据类型 | 说明 |
|---------|------|
| 产品照片 | 显示缺陷或损坏情况 |
| 包装照片 | 展示运输过程中的外包装状态 |
| 交易记录 | 包括订单号、发货时间、收货时间 |
| 检测报告 | 第三方检测机构出具的质量检测结果 |
| 客户沟通记录 | 与买家的邮件、聊天记录等 |

## 三、证据保存建议
- 所有证据应保留至少 2 年，以备后续争议处理。
- 建议使用云存储或专业物流系统备份数据。

## 四、索赔流程
1. 收到质量问题反馈后，第一时间确认事实。
2. 与买家沟通解决方案，如退换货、维修或赔偿。
3. 根据合同条款，提供相应证据支持索赔请求。
4. 若协商不成，可依据合同条款提起法律诉讼。

## 五、注意事项
- 不同国家对质量异议期规定不同，需了解目标市场法规。
- 保留完整证据链是成功索赔的关键。
- 建议在合同中明确质量异议期和索赔条款。
