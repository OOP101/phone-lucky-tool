# 电池运输的 UN38.3、MSDS 与危包证

## 一、电池运输的基本要求
根据联合国《危险品运输建议书》（UN38.3）规定，锂电池在航空运输中需通过安全测试并取得认证。运输前必须提供以下文件：
- UN38.3 测试报告
- MSDS（化学品安全技术说明书）
- 危包证（危险货物包装证书）

## 二、UN38.3 测试流程
1. 提交样品至具备资质的检测机构；
2. 检测项目包括：高度模拟、温度循环、振动、冲击等；
3. 测试合格后获得 UN38.3 报告。

## 三、MSDS 编制要点
MSDS 需包含以下内容：
| 项目 | 内容 |
|------|------|
| 化学名称 | 锂离子电池 | 
| 危险性 | 易燃、易爆 | 
| 应急措施 | 灭火器、通风、隔离 | 
| 储存条件 | 避免高温、潮湿环境 | 

## 四、危包证申请流程
1. 向海关或指定机构提交申请表；
2. 提供产品说明、测试报告及包装方案；
3. 审核通过后获得危包证编号。

## 五、注意事项
- 不同运输方式（空运、海运、陆运）要求不同；
- 电池容量超过 100Wh 需额外审批；
- 运输前务必确认收货方是否接受危险品运输。
