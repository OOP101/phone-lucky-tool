# SP 商品推广广告基础架构

## SP 广告类型与定位
SP（Sponsored Products）广告是亚马逊最常用的广告形式，支持关键词、商品和品牌三种投放方式。
- **关键词广告**：按关键词匹配投放，适合新品推广。
- **商品广告**：针对特定商品投放，适合引流。
- **品牌广告**：适用于品牌注册卖家，提升品牌曝光。

## 广告预算与出价策略
- **每日预算**：建议从 $10 开始，逐步增加。
- **出价方式**：可选择自动出价（由亚马逊决定）或手动出价（控制更精细）。
- **竞价策略**：建议初始出价为产品价格的 10%-20%。

## 广告优化建议
1. **关键词选择**：使用工具（如 Helium 10、Jungle Scout）筛选高转化关键词。
2. **广告组划分**：按产品类别、关键词类型分组，便于管理。
3. **A/B 测试**：尝试不同标题、图片、描述，提升点击率。
4. **转化率优化**：优化产品页面，提升点击后转化。
5. **定期调整**：每周分析数据，调整出价与关键词。

## 常见问题与解决方案
| 问题 | 解决方案 |
|------|----------|
| 广告无展示 | 检查预算、出价、关键词匹配 |
| 点击率低 | 优化标题、图片、描述 |
| 转化率低 | 优化产品页面、价格、评论 |
| 花费过高 | 调整出价、关键词、预算 |
| 无效果 | 检查产品是否合规、是否有库存 |
