# TikTok 短视频带货口播脚本

## 一、口播脚本结构设计
TikTok短视频带货口播脚本需遵循“黄金三秒法则”，前3秒必须抓住用户注意力。建议采用以下结构：

- **开头（0-3秒）**：吸引眼球，如“你还在用这个？太老土了！”
- **中间（4-15秒）**：介绍产品功能与优势，突出卖点
- **结尾（16-30秒）**：引导点击购买，如“点击购物车，马上抢购”

## 三、口播节奏控制

- 每句话控制在2-3秒内，语速适中
- 关键词重复2次以上，增强记忆点
- 配合手势或画面切换，提升观看体验
