# 选品的数据维度与调研方法

## 一、核心数据维度
- **市场需求**：搜索量、竞争指数、转化率；
- **利润空间**：毛利率、平台佣金、广告成本；
- **供应链能力**：供应商稳定性、交货周期、质量控制；
- **政策合规**：是否需要认证、是否受限制；
- **趋势预测**：季节性、热点事件、社交媒体热度。

## 二、数据来源与工具

| 数据来源 | 工具/平台 |
|----------|-----------|
| 电商平台 | Amazon、eBay、AliExpress |
| 社交媒体 | TikTok、Instagram、Facebook |
| 分析工具 | Jungle Scout、Helium 10、Google Trends |
| 行业报告 | Statista、艾瑞咨询、海关数据 |

## 三、调研方法
- **关键词分析**：使用Google Keyword Planner、Amazon Search Bar筛选高潜力关键词；
- **竞品分析**：观察同类产品的销量、评价、定价策略；
- **用户调研**：通过问卷、评论区、社交平台收集用户反馈；
- **数据对比**：利用Excel或数据分析工具进行多维度比对。

## 四、选品决策模型
- **评分表法**：设置权重（如市场需求30%、利润20%、供应链20%、政策15%、趋势15%），对每个产品打分；
- **优先级排序**：按综合得分排序，优先选择高分产品。

## 五、注意事项
- 避免盲目跟风，需结合自身供应链能力；
- 关注政策变化，避免选品后无法上架；
- 保持灵活调整，定期更新选品策略。
