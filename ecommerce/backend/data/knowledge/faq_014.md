# 商业发票与装箱单的制作要点

## 一、商业发票（Commercial Invoice）

### 1. 必须包含的信息
| 项目 | 内容 |
|------|------|
| 卖方信息 | 公司名称、地址、联系方式 |
| 买方信息 | 公司名称、地址、联系方式 |
| 货物描述 | 品名、规格、数量、单价 |
| 总金额 | 人民币或外币，注明汇率 |
| 运输信息 | 发货地、收货地、运输方式 |
| 付款条件 | 信用证、预付、账期等 |

### 2. 注意事项
- 金额必须与合同一致；
- 货物描述应清晰准确，避免歧义；
- 采用英文或目的国语言填写。

## 二、装箱单（Packing List）

### 1. 必须包含的信息
| 项目 | 内容 |
|------|------|
| 装箱编号 | 每个包装箱的唯一标识 |
| 货物明细 | 品名、数量、重量、体积 |
| 包装类型 | 纸箱、木箱、托盘等 |
| 特殊说明 | 如易碎品、危险品标注 |

### 2. 注意事项
- 每个包装箱需单独列出；
- 重量和体积需精确，避免超重或超尺寸；
- 与商业发票内容保持一致，避免矛盾。
