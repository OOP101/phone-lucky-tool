# 工具汽配类英文 Listing 文案范例

## 1. 标题撰写规范
工具汽配类产品的英文标题需包含核心关键词、产品型号、功能描述及适用场景。建议控制在 60 个字符以内，确保搜索引擎友好。

示例：
> 2023 New 1/2" Drive Socket Wrench Set for Car Repair - 18-Piece, Chrome Vanadium Steel, Durable & Lightweight

## 2. 产品卖点清单
列出 5-7 个核心卖点，使用简洁有力的动词和形容词，突出产品优势。

| 卖点 | 描述 |
|------|------|
| High Quality | Made from chrome vanadium steel for long-lasting use |
| Durable | Resistant to wear and tear under heavy usage |
| Easy to Use | Ergonomic design for comfortable grip and control |
| Wide Application | Suitable for car, motorcycle, and industrial repairs |
| Complete Set | Includes 18 pieces of sockets and a ratchet wrench |

## 3. 详细描述结构
详细描述应分段落，每段不超过 4 句话，内容包括产品特点、使用方法、售后服务等。

> This 1/2" drive socket wrench set is ideal for both professional mechanics and DIY enthusiasts. The chrome vanadium steel construction ensures durability even in harsh environments. Each socket is precision-machined for a perfect fit on bolts and nuts. We offer a 1-year warranty and free replacement if any part is damaged.

## 4. 关键词优化建议
建议在标题、五点描述、商品详情页中合理分布关键词，避免堆砌。常见关键词包括：socket set, wrench, car repair tools, automotive tools, mechanic tools 等。

## 5. 图片与视频要求
产品图片需展示多角度细节，主图需清晰显示产品名称和型号。建议提供 5 张以上高质量图片，并可添加 1-2 分钟的产品演示视频。

## 6. 法规与认证信息
如产品涉及欧盟 CE 认证或美国 FCC 认证，需在商品详情页明确标注。例如：
> CE Certified - Complies with EU safety standards for electrical equipment
