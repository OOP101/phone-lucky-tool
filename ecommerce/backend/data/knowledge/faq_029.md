# MOQ 起订量与混批拿货规则

## 一、MOQ 定义与设定标准
- **MOQ（Minimum Order Quantity）**：即最小起订量，是供应商接受订单的最低数量；
- 一般设定范围为 **50-500 件**，视产品复杂度与生产周期而定。

## 二、混批拿货规则
- 混批是指客户同时订购多种产品，且每种产品的数量均达到 MOQ；
- 供应商通常允许混批，但需满足以下条件：
  - 每种产品至少达到 MOQ；
  - 总订单金额不低于 **5000 元**；
  - 交货时间一致。

## 三、谈判技巧与策略
- 若客户无法满足 MOQ，可提供 **分批发货** 或 **分期付款** 方案；
- 对于高价值产品，可适当降低 MOQ 以促成交易；
- 与供应商协商 **阶梯 MOQ**，即订单越大，MOQ 越低。

## 四、注意事项
- 确保 MOQ 与生产能力匹配，避免超负荷；
- 与客户确认是否接受混批，避免后续纠纷；
- 记录每次 MOQ 变更情况，便于后续对账。

## 五、建议条款
- 合同中应注明：“若客户订购多种产品，且每种产品均达到 MOQ，则视为混批订单。”
- 对于首次合作客户，可提供 **MOQ 优惠** 以促进成交。
