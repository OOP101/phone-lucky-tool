# 亚马逊业务报告数据解读

## 业务报告类型
亚马逊提供多种业务报告，包括：
- Sales Report（销售报告）；
- Inventory Report（库存报告）；
- Performance Report（绩效报告）；
- Advertising Report（广告报告）。

## 关键指标解读
| 指标 | 说明 |
|------|------|
| Units Sold | 实际销售数量 |
| Total Revenue | 总销售额 |
| Average Price | 平均售价 |
| Order Defect Rate | 订单缺陷率（低于1%为佳） |
| Fulfillment Time | 发货时间（建议控制在2天内） |

## 数据分析建议
- 定期对比历史数据，识别增长或下滑趋势；
- 分析广告ROI，优化广告预算分配；
- 监控库存周转率，避免滞销；
- 根据客户反馈优化产品与服务。

## 常见问题处理
- 若数据异常，检查是否因系统错误或订单取消导致；
- 若订单缺陷率过高，需优化物流与客户服务；
- 若广告花费高但转化低，需优化广告关键词与落地页。
