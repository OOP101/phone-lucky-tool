# 侵权投诉：商标、专利与版权

## 侵权类型与法律依据

| 侵权类型 | 法律条款 | 举例 |
|----------|-----------|------|
| 商标侵权 | 《商标法》第57条 | 使用他人注册商标 |
| 专利侵权 | 《专利法》第11条 | 未经许可制造、销售专利产品 |
| 版权侵权 | 《著作权法》第10条 | 未经授权使用他人作品 |

## 投诉流程与应对

1. **收到投诉通知**：亚马逊会发送侵权通知邮件，附带侵权链接及权利人信息。
2. **核实内容**：确认是否涉及侵权，如确有问题需立即下架商品。
3. **提交申诉**：填写亚马逊“Dispute Resolution”表格，说明不侵权理由。
4. **补充材料**：如商标注册证、专利证书、版权登记证明等。
5. **等待审核**：通常需3-7个工作日。

## 预防措施建议

- 在发布前进行商标、专利、版权检索（可用Google Patents、USPTO、商标局官网）。
- 使用原创设计、文案与图片，避免直接复制。
- 购买品牌保护服务（如Brand Registry）提升维权能力。
