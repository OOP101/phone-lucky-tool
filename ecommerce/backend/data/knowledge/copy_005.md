# 户外露营类英文 Listing 文案范例

## 一、标题示例
```
Portable Camping Tent 3-Season 4-Person with Rainfly and Groundsheet
```

## 二、五点描述（Bullet Points）
- 3-season design for spring, summer, fall use
- 4-person capacity for family or group camping
- Included rainfly and groundsheet for added protection
- Lightweight and easy to set up
- Durable fabric with UV resistance

## 四、注意事项
- 英文文案需符合亚马逊 SEO 规则；
- 使用专业户外术语（如 "rainfly", "UV resistant"）；
- 避免夸大宣传（如 "best tent ever"）。
