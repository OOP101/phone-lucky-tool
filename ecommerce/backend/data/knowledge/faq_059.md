# 贴标、换标与外箱唛头规范

## 贴标操作流程

1. **确认标签内容**：包括产品名称、型号、产地、规格、安全标识等；
2. **提供标签模板**：建议提供PDF或AI格式文件；
3. **样品确认**：在量产前进行贴标样品确认；
4. **批量贴标**：按订单数量分批贴标，确保一致性；
5. **质检抽查**：随机抽检贴标位置、内容、清晰度。

## 换标注意事项

- 换标需提前30天通知供应商；
- 新标签需与原标签保持一致的尺寸、字体、颜色；
- 换标后需重新进行样品确认；
- 若涉及多语言版本，需提供翻译文件并经客户确认。

## 外箱唛头规范

| 内容项 | 要求 |
|--------|------|
| 产品名称 | 必须清晰可见 |
| 数量 | 用数字标注 |
| 重量 | 单位为kg |
| 产地 | 中国/XX国家 |
| 运输标志 | 可选，但需统一 |

## 供应商沟通要点

- 明确贴标位置、内容及格式；
- 提供标签源文件及翻译文件；
- 要求供应商提供贴标过程照片；
- 在合同中注明标签错误处理方式。

## 法规与条款参考
- 《进出口商品检验法实施条例》第21条：进出口商品的标签必须真实、准确；
- 国际贸易中，外箱唛头需符合《国际海运危险货物规则》（IMDG Code）相关要求。
