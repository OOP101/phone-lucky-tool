# 多语言本地化翻译要点

## 一、翻译基本原则

1. **准确传达信息**：确保技术参数、功能描述无误。
2. **符合文化习惯**：避免直译，如“谢谢”在某些文化中可能不常用。
3. **语法规范**：遵守目标语言语法规则，如德语名词首字母大写。

## 二、关键内容翻译要求

| 内容类型 | 翻译要求 |
|----------|------------|
| 产品标题 | 精准、易懂、符合SEO |
| 产品描述 | 专业、完整、符合当地表达 |
| 促销文案 | 情感化、吸引力强 |
| FAQ | 清晰、直接、解答常见问题 |

## 三、本地化注意事项

- **数字格式**：如日期、货币、单位需符合目标国家习惯
- **颜色含义**：如红色在某些文化中代表喜庆，在另一些文化中代表危险
- **宗教禁忌**：避免使用敏感词汇或符号

## 四、翻译流程建议

1. 选择专业翻译团队或本地化服务商
2. 提供完整产品资料与术语表
3. 本地化后进行多轮校对
4. 发布前进行多语言测试
5. 持续收集用户反馈，优化翻译内容
